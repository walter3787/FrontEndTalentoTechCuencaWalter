# SMD Electrónica

Sitio web desarrollado como proyecto de Frontend para mostrar productos y servicios de mantenimiento de electrodomésticos.  
Incluye catálogo de productos, descripción de servicios, formulario de contacto funcional y mapa de ubicación.

## 🚀 Características
- **Estructura semántica HTML** con `header`, `nav`, `main`, `section`, `footer`.
- **Formulario de contacto** conectado a [Formspree](https://formspree.io) para envío de datos.
- **CSS externo** con estilos aplicados a header, footer y navegación.
- **Google Fonts** para tipografía moderna.
- **Diseño responsivo** mediante Flexbox, Grid y Media Queries.
- **Contenido multimedia**: imágenes de productos e integración de Google Maps.
- **Hosting gratuito** en GitHub Pages:  
  👉 [Ver sitio en línea](https://walter3787.github.io/FrontEndTalentoTechCuencaWalter/)

## 📂 Estructura del proyecto
- `index.html` → Página principal.
- `css/estilos.css` → Estilos globales.
- `img/` → Imágenes de productos e íconos.
